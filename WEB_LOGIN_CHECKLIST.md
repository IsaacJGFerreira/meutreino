# Checklist da versão web

Quando o site abrir, mas o acesso não avançar, confira no painel do Firebase:

1. O método Email/Password precisa estar ativo.
2. O domínio do GitHub Pages precisa estar autorizado.
3. A configuração web precisa vir do mesmo projeto usado pelo app Android.

Depois de alterar qualquer configuração, rode novamente o workflow Deploy web desktop em Actions.
