# MeuTreino Web

Projeto web (React + Vite + TypeScript) do sistema MeuTreino.

## Pré-requisitos

- Node.js 20+
- npm 10+

## Configuração

1. Copie o arquivo de exemplo:

```bash
cp .env.example .env
```

2. Preencha as variáveis `VITE_*` com as credenciais do Firebase Web.

## Executar em desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```
